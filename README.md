# LCNE_transcriptomics
The transcriptomics analysis for LC-NE mmanuscript. 

There are three folders under `./notebooks/`: `snRNA`, `MERFISH` and `retrpseq` corresponding to the anlaysis for each dataset. 

The data can be generated from the other repo `LCNE_transcriptomics_preprocessing`, and after its run you need to attach the generated data asset to this repo. 


`plot_all_*_figs.ipynb` is the main notebook that creates the main figures used in the paper. there are a few auxillary notebooks that are used mostly to generate supplemental figs.
